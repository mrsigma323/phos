# Phos

Web de Phos: la luz de la fe ortodoxa para cada día.

- `/` — página principal (ayuno y fiestas de hoy, lecturas, reflexión, oraciones, calendario).
- `/biblia/` — la app completa (Biblia en 9 idiomas, cursos, salud, hábitos), instalable como PWA.
- `aviso-legal.html`, `privacidad.html`, `cookies.html` — textos legales.

Se publica en Hostinger desde la rama `main` (hPanel → Avanzado → GIT).
