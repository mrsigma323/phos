# Phos · Biblia electrónica

Web y app instalable (PWA) con las Biblias de las principales ramas cristianas, cursos, salud, hábitos cristianos y calendario litúrgico.

- `index.html`: la aplicación completa.
- `data/`: textos bíblicos (dominio público; ver créditos dentro de la app).
- `manifest.webmanifest`, `sw.js` e iconos: instalación en el móvil y lectura sin conexión.

Se publica en Hostinger desde la rama `main`.
